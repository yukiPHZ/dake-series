## PACK_BODY

### 概要

PDFの結合、画像からPDF作成、画像リサイズ、画像のA4貼り付けをまとめたパックです。
書類整理でよくある小さな作業を、ひとつずつ軽く処理できます。

### できること

- 複数PDFをひとつにまとめる
- 画像ファイルをPDFにする
- 画像サイズをまとめて調整する
- 画像をA4用紙に配置して印刷しやすくする

### 使い方

1. パックZIPを解凍します。
2. 使いたいアプリのZIPを解凍します。
3. 各アプリの `.exe` を起動して使います。

### 注意事項

- Windows向けです。
- 大切なファイルは事前にバックアップしてください。
- 各アプリの詳しい使い方は、収録アプリ側のREADMEを確認してください。
