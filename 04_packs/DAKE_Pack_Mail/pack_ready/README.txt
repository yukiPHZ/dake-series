DAKE メール準備パック

集める、整える、下書きにする。
送信前までを静かにまとめるWindows向けPackです。

収録アプリ:
- Dakeメールリスト: Outlookの.msgメールから連絡先をCSV化します。
- Dakeメールアドレス整形: 名前付き表記やセミコロン区切りの宛先を抽出・整形します。
- Dakeメール下書き: CSV名簿からOutlookの個別下書きを作成します。

使い方:
1. このPack ZIPを解凍します。
2. appsフォルダ内の各アプリZIPを解凍します。
3. 必要なアプリのexeを起動して使います。
4. Dakeメール下書きで作ったメールは、Outlookで宛先・件名・本文・添付を確認してから送信してください。

重要:
- メールは自動送信しません。
- Dakeメール下書きはWindows版Microsoft Outlook Classicを前提とします。
- New Outlook / Web Outlookでは動作しない場合があります。
