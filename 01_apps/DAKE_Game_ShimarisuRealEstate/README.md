# Dakeしまりす不動産

不動産買取再販をテーマにした、Python + Pygame製の短編シミュレーションゲームです。

## 起動方法

```powershell
pip install -r requirements.txt
python main.py
```

## ゲーム内容

案件を調査し、買取し、リフォームまたは現況販売を選び、180日以内に資金を増やします。

`信用` は、仲介業者からの信用、売主対応の丁寧さ、買主への説明責任、無理な仕入れをしない姿勢、成約実績をまとめた評価です。
