# DAKE Backup

消さない。静かに残す。

DAKE Backup は、ローカルにある正本フォルダを、指定した避難先フォルダへバックアップ保存するための DAKE_series アプリです。

## 大事な考え方

- このアプリは同期アプリではありません。
- 削除は伝播しません。
- ローカル正本を避難先へコピーします。
- バックアップ先のファイルを自動削除しません。
- Google Drive 専用ではありません。普通のフォルダならどこでも指定できます。
- Google Drive、USBメモリ、外付けSSD、別ドライブなどを避難先にできます。
- BRAINZ_ROOT の保険として使う想定です。

Drive は記憶庫ではなく避難先。正本はローカルにある、という前提で動きます。

## 仕様

- 正本フォルダと避難先フォルダを選択できます。
- 「差分を見る」で追加、更新、退避、削除予定を表示します。
- 「残す」で一方向コピーを実行します。
- 正本側で削除されたファイルがあっても、避難先からは削除しません。
- 同名ファイルがあり内容が違う場合、上書き前に避難先の旧ファイルを退避します。
- 退避先は `backup_archive/YYYYMMDD_HHMMSS/` 配下です。
- 差分表示の削除予定は常に `0` です。
- ログは `data/logs/backup_YYYYMMDD_HHMMSS.log` に保存します。
- 設定は実行時に自動生成される `data/settings.json` に保存します。
- `data/settings.json` は個人パスを含むため Git 管理しません。初期値は `data/settings.example.json` を参照してください。
- 初回起動時の設定は空欄で問題ありません。
- 手動実行のみです。自動実行、USB自動検知は実装していません。

## 使い方

```bat
python main.py
```

1. 正本フォルダを選びます。
2. 避難先フォルダを選びます。
3. 「差分を見る」で内容を確認します。
4. 「残す」で保存します。

## 動作確認

```bat
python main.py --launch-check
python main.py --smoke-test
```

`--smoke-test` では、一時フォルダを使って以下を確認します。

- 追加ファイルがコピーされること
- 更新ファイルが `backup_archive/YYYYMMDD_HHMMSS/` へ退避された後にコピーされること
- 元フォルダで削除したファイルが、先フォルダから削除されないこと
- `settings.json` が保存されること
- `data/logs/` にログが出ること

## ビルド

```bat
build.bat
```

PyInstaller が使える環境では `dist\DakeBackup.exe` を作成します。
