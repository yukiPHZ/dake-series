# Dake潜って獲る

## アプリ概要

`Dake潜って獲る` は、80年代〜初期90年代のLCD携帯ゲーム風に遊べるDAKE番外ミニゲームです。船から海へ潜り、銛で小魚・大魚・イカ・宝箱を獲って、サメを避けながら船へ戻ると得点になります。

単機能・軽量・即起動を優先し、外部画像素材や追加依存を使わない Python / Tkinter 製のCanvasゲームです。

## 操作方法

- `Enter`: 開始 / 再開
- `R`: リスタート
- `↑` / `W`: 上へ移動
- `↓` / `S`: 下へ移動
- `←` / `A`: 左へ移動
- `→` / `D`: 右へ移動
- `Space`: 銛を突く
- `T`: モード切替（待機中 / ゲームオーバー中のみ）
- `M` / `Esc`: メニューへ戻る
- `P`: 一時停止 / 再開

## ゲームルール

- ダイバーは船の位置から開始します。
- 海中は横7列 × 縦8段のマス移動です。
- 起動時はメニューを表示し、NORMAL / TIMELESS を選んで開始します。
- 通常モードは60秒制です。`TIME` が0になると終了します。
- タイムレスモードはライフが尽きるまで続き、時間経過で少しずつ難しくなります。
- 海中で `Space` を押すと、向いている方向の隣接1マスだけを銛で突きます。
- 銛が魚・イカ・宝箱に当たると、獲物保持状態になります。
- 宝箱は海底付近にだけ出現します。
- 獲物を取った時点では得点せず、船へ戻ると得点になります。
- `HOLD` は最大3スロットです。小魚は1、大魚とイカは2、宝箱は3スロット使います。
- 得点後、`HOLD` は `0/3` に戻ります。
- `AIR` は海中で減り、深く潜るほど消費が増えます。船へ戻ると回復します。
- サメに触れるとライフが1減ります。
- 獲物保持中にサメに触れると、保持中の獲物も失います。
- 小魚・大魚・イカはゆっくり移動します。イカはたまに上下へも動きます。
- HOLDが重いほど、ダイバーの移動間隔が少し長くなります。
- 重いHOLDのまま無操作でいると、少しずつ沈みます。
- 低頻度でクラーケンが出現し、一定時間ダイバーを追います。
- ライフ0でゲームオーバーです。
- ゲームオーバー時は `Enter` または `R` で再開できます。
- ゲーム中・一時停止中・ゲーム終了後は `M` / `Esc` でメニューへ戻れます。
- BESTスコアは `diver_catch_config.json` に保存されます。

## 得点ルール

- 小魚: 10点
- 大魚: 30点
- イカ: 50点
- 宝箱: 100点

## Phase2更新

- ダイバーの見た目にボンベ、足ヒレ、マスク、シュノーケル風の線を追加しました。
- 海中マップを横7列 × 縦8段へ拡張し、薄い層表現と岩礁・サンゴ背景を追加しました。
- 小魚を最大3匹まで保持できる3スロットHOLDに変更しました。
- 新しい獲物としてイカを追加しました。
- 大漁時・重い獲物保持時の移動速度ペナルティを追加しました。
- 魚とイカのゆっくりした移動を追加しました。
- サメの出現位置と行選択を調整しました。

## Phase3更新

- 銛の射程を隣接1マスに調整しました。
- キー長押しによる連続移動・連続銛突きを禁止しました。
- 宝箱を海底付近限定に変更しました。
- `AIR` 表示と深度による酸素消費を追加しました。
- 大漁時・重い獲物保持時の無操作沈下を追加しました。
- クラーケンを追加しました。
- 通常モードを60秒制に変更しました。
- タイムレスモードを追加しました。
