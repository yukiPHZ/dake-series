# Dakeマンション工程表

マンション管理会社へ提出するための、リフォーム工事工程表を作成します。工事進捗管理ではなく、管理会社提出用の見やすい工程表を作成するためのDAKEシリーズのWindows向け単機能アプリです。

## アプリ説明

- 引渡し日の3日後を着工日とし、着工日を1日目とする45日目を完工日に自動計算します。
- 工期は土日祝を含む45日間です。
- 自動工程は土日および日本の祝日を除いて配置します。
- 固定の工事項目に、合計28営業日の初期日程を自動入力します。45日間に配置できない場合は、工程日数や工期を変更せず手動調整を案内します。
- 45日工期内の残りの工事可能日は、工程を引き延ばさず予備日として自然に分散します。
- PDFの横軸には土日祝を表示し、平日の祝日列も淡い休日背景と淡い赤の曜日文字で識別できます。自動工程バーは土日祝に表示しません。
- 工事行はチェックしたものだけPDFに出力し、未出力行の空白は残さず上に詰めます。
- 自由工事欄を2行用意しています。入力してチェックした自由工事だけPDFに出力します。
- 手動入力では土日祝の日付も指定できます。
- 手動で休日工事を指定した場合は、PDF作成前に確認します。「はい」では入力どおり出力し、「いいえ」ではPDF作成を中止して画面へ戻ります。
- 出力は「リフォーム工事工程表」タイトルのA3横1枚PDFです。
- PDFは出力日時付きのファイル名で保存し、同名ファイルがある場合は連番を付けて上書きを避けます。
- PDF作成後、保存先フォルダを自動で開きます。
- 会社支店名、担当者名、連絡先は次回起動時に自動入力されます。
- PDF内にはDAKEのコピーライトやブランド表記を出しません。

## 使い方

1. 現場名、会社支店名、担当者名、連絡先を入力します。
2. 引渡し日を `YYYY-MM-DD` 形式で入力します。
3. 「日程を自動入力」を押します。
4. 必要に応じて各工程の開始日・終了日を修正します。
5. PDFに出力する工事だけチェックします。
6. 任意の工事がある場合は自由工事欄に工事名・開始日・終了日を入力してチェックします。
7. 「保存先を選ぶ」でPDFの保存先を指定します。
8. 「PDFを作成」を押します。
9. `mansion_schedule_工程表_YYYYMMDDHHMM.pdf` のように出力日時付きのPDFが作成されます。
10. PDF作成後、保存先フォルダが自動で開きます。

## 注意事項

本工程表は、マンション管理会社への提出・申請補助を目的とした参考工程表です。実際の施工工程・管理規約・申請条件に応じて、施工会社・管理会社へ確認してください。
