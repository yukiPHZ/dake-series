# Dake画像iPhoneToPC

iPhoneの写真を、同じWi-Fi上のWindows PCへ送るDAKEシリーズ用デスクトップアプリです。
PC側で受信画面を起動し、iPhoneのカメラでQRコードを読み取ってブラウザから写真を送信します。

## 使い方

1. `DakeImage_iPhoneToPC.exe` を起動します。
2. PC画面に表示されたQRコードをiPhoneのカメラで読み取ります。
3. iPhoneのブラウザで開いた画面から写真を選び、送信します。
4. 受信した写真はWindowsのDownloads直下へ保存されます。
5. 別の写真を送る場合は、同じブラウザ画面からもう一度選択して送信できます。

## 仕様

- iPhone側の専用アプリは不要です。
- iPhone専用です。Android対応は含めません。
- Safari / Chrome で動作想定です。
- iPhoneとWindows PCは同じWi-Fiに接続してください。
- 外部サーバー、クラウド保存、ログイン、履歴管理は使いません。
- 写真はDownloads直下へ保存します。専用フォルダは作りません。
- JPG/JPEG/PNGは原則そのまま保存します。
- HEIC/HEIFはJPGへ変換して保存します。
- 300枚程度の写真転送を想定していますが、1回の送信は30〜50枚ずつに分けると安定します。
- 100枚以上を一度に選ぶと、iPhone側の写真選択画面が止まる場合があります。
- 送信ごとに成功件数と失敗件数を表示します。
- 受信完了後、成功ファイルがある場合はDownloadsを自動で開きます。
- 同名ファイルがある場合は上書きせず、末尾に `_1`, `_2` を付けて保存します。
- 起動ごとにランダムURLを発行し、URLを知らない端末からのアクセスを拒否します。
- 会社Wi-Fiでは端末同士の通信が止められている場合があります。
- Windowsファイアウォールの許可画面が出た場合は、アクセスを許可してください。

## DAKEシリーズ

DAKEシリーズは、単機能・軽量・高速・安定を優先した「シンプルそれDAKEシリーズ」です。
このアプリは、iPhone写真をPCへ送ることだけに絞っています。
