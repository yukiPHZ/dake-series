# Dake BGM Loop Phase 2

のんきなループを、静かに作るための短いBGMループ生成補助アプリです。

## 追加・調整

- Phase 1のMock生成UIをレビューし、生成中の状態表示を整理
- 生成後すぐにPreviewできる導線を確認
- 「この音を採用」「次を作る」の操作導線を追加
- seed / mood / duration / license notice / favorite状態を画面で確認できる表示を追加
- `settings.json` をGit管理対象外に変更し、`settings.example.json` を追加
- ACE-Step実生成は未接続のまま、adapter準備のみ継続

## 注意

生成音声の商用利用可否は、使用モデル・素材・公開先の規約に依存します。
YouTube等で公開する前に、使用モデルのライセンスを確認してください。
