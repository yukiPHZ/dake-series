# DakePDF抽出

1つのPDFを開いたまま、必要なページを何度でも連続して抽出するDAKEアプリです。

## v1.0.0

DakePDF抽出の初回正式版です。

## 主な内容

- PDF 1ファイルの読み込み
- `PDFを追加`、空状態中央の選択領域、ドラッグ＆ドロップでの読み込み
- 全ページのサムネイル一覧表示
- 読み込み済みPDFのリフレッシュ
- クリック、再クリック、Shift+クリックによるページ選択
- Enterで抽出、Escで選択解除
- 選択ページを1つのPDFにまとめて保存
- 選択ページを1ページずつ保存
- 保存成功後もPDFとスクロール位置を維持
- 保存成功後の自動選択解除
- 保存成功後の保存先フォルダ表示と既存Explorer windowの前面化
- 抽出済みページの薄い表示とチェック表示
- サムネイルサイズ変更

## 動作環境

- Windows
- インストール不要の単体exe
