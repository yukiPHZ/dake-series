## 実際に確認した操作と境界

Canvas、実画像画素、ベクターパス、worker、preload、IPC、原子的保存を実Electron内で動かしました。取り消し・やり直し、画像調整、クリップの解除、グループ、集合演算、ノード、文字アウトライン、ラスタライズ、v1互換とv2メタデータの保存を確認しています。

自動制作ハーネスはDOMのボタン・入力欄とCDPのマウス・実ファイルドロップを操作します。ネイティブファイルダイアログの返答だけを試験専用パスへ差し替え、rendererの保存APIは置き換えません。手動操作ではWindowsの実保存ダイアログから `test-output/manual-production-profile/manual-review.dake` を保存し、Noto Sans JPの埋込みを確認しました。

保存・復旧試験は、前回保存バックアップ、失敗時の現作品保持、破損候補からの復旧、上書きによる元素材保護を検査しました。再起動試験は異なるPIDを使い、正常終了処理を通らない `app.exit()` 後の復旧候補を次プロセスで開いています。ディスクの置換途中の強制終了や物理電源断を模擬したものではありません。

フォントは実HTTPSでバイナリと許諾を取得し、Windows TTCから選択書体を抽出する境界も検査しました。カタログ全1936書体の実取得・全字形・全許諾全文を個別確認したわけではありません。取得した書体にはライセンス、版、ハッシュを残します。作品本文をGoogleの `text=` APIへ渡しません。

PDFは専用workerで白背景合成したRGB画素をFlate圧縮して構築します。3試験のページ寸法誤差は0.00001pt未満でした。mm指定の文書作成時に整数pxへ丸めるため、300dpiでは指定mmとの差が最大約0.043mmあります。ベクターPDF・CMYK・PDF/Xや入稿受理の証明ではありません。

配布EXEの手動検証では、同梱の名刺を実Windowsダイアログから開き、名前レイヤーの「緑野 花」を「緑野 花子」へ変更しました。別名の `.dake` と1146×720 PNGを `test-output/manual-packaged-0.2/` に保存し、実ファイルの文字・300dpi・mm・フォントと許諾の埋込みを検査、出力PNGを目視しました。元の同梱作品のSHA256は不変です。Alt+F4での正常終了後に同じ配布EXEを再起動し、保存ファイルの文字・配置・ガイドが戻ることを画面で確認しました。手動操作の対象はこの名刺であり、4種類すべての手動制作を主張するものではありません。

素材はコード生成の抽象画像・自作SVG・架空テキストです。元PNG / SVGのSHA256を操作前後で照合します。保存後に最初のプロセスを終了し、新しいprofileの別PIDで通信を禁止して再開、文字・図形を再編集、別名保存して5形式へ出力します。

再開前後は全テキスト・フォント記述子・幾何情報・文書メタデータを比較し、PNGの完全一致と許容差一致を区別します。標準の許容条件は最大色差3/255・差分画素2%以下・平均RGB差0.02以下。名刺の読み込んだSVG円の輪郭だけは最大8/255・差分画素0.1%未満・平均RGB差0.001未満を条件とし、差分領域が当該円だけであることと幾何・文字情報一致を別途検査します。原因はキャッシュ量子化の可能性があるものの確定していません。完全な画素一致とは報告しません。

PDFは別経路のpypdfでページとMediaBoxを読み、Popplerで描画しPNGと比較します。SVGはベクター要素・外部参照なし・画像としての復号を確認しますが、他アプリでの全編集互換を保証しません。生テキストのSVGにはGoogle Fontsを含む書体バイナリを埋め込んでいません。

## 応答性の実測

次は同じPCでの単回測定です。「完了時間」と「イベントループ最大間隔」を区別し、環境一般の保証値にはしません。

| 操作 | 12MP 完了 / 最大間隔 | 32MP 完了 / 最大間隔 |
| --- | --- | --- |
| 画像調整worker | 387 / 43 ms | 693 / 91 ms |
| 調整付き画像の再読込み | 234 / 49 ms | 618 / 105 ms |
| 調整付き画像の筆操作完了 | 278 / 57 ms | 782 / 194 ms |

32MPを11回描いた履歴は13状態・概算90.1 MiBへ剪定され、取り消しで画素が戻りました。worker結果とCPU参照の画素一致、処理中の競合防止、原画素保持を確認しています。

非同期PNG圧縮では高エントロピーのA4相当（2480×3508）の28.3 MiB出力が447 ms / 最大117 ms、32MPの104 MiB出力が1528 ms / 最大313 msでした。旧同期方式の32MPでは最大1235～1603 msを観測したため、toBlobとFileReaderへ変更しました。元と新方式の復号画素SHA256は一致しています。PNG圧縮が非同期でも最初の描画などには同期負荷が残り、常時100 ms以内を満たすものではありません。32MP PDFのネイティブworker処理は2194 ms / メイン最大137 msでした（`evidence/native-pdf-performance.json`）。

文字アウトライン12ケースは元文字と輪郭のIoU 0.902999～0.956219、面積比0.970086～0.998103。フォント描画とパス描画のhinting / アンチエイリアス差を含みます。アウトライン後の保存・再読込みPNGは12ケースすべて完全一致し、workerは11～73 ms、イベントループ最大17 msでした。

過去の非表示ウインドウで測った約1007 msのrequestAnimationFrame間隔は非表示時の描画抑制で、UIフリーズの測定値に用いません。

## 検証中に直した問題

- 文字パネルが下へ隠れる配置を改め、固定6書体から実PC・Google Fontsの選択へ変更。
- 新規作成の不正dpi・セーフ領域を作品置換前に検査。失敗時に旧作品を維持。
- `.dake`ドロップ後の保存先・未保存状態、表示切替による誤ったdirty更新を修正。
- 書体取得中の検索切替競合、容量超過、未使用フォントの除去とUndoでのFace復帰を保護。
- Fabricの保存精度を12桁へ上げ、objectCaching属性を保持してアウトライン再開時の差を解消。
- パネル幅変更をwindowのpointermove / up / cancel / blurで扱い、実マウスで安定して終了するよう修正。
- PNG同期圧縮を非同期化し、開始時の名前・寸法・dpiを固定。効かない形式の品質・倍率欄を無効化。

制作QA側でもmm欄へpx値を入れた誤りとFontFace.familyの引用符比較を修正しました。画面目視で空の印刷作例を検出し、作例の再生成と非白画素・画面内要素検査を追加しました。失敗した途中作例を最終成果物へ採用しません。

最終レビューでさらに、作品作成時のdpi・塗り足しを一つの初期履歴へまとめ、Undoで初期dpiへ戻らないよう修正。同じfamily / 太さ / スタイルの異なるフォントhashをUndoしても元FaceとPNGへ戻るよう修正しました。保存中の作品切替、同作品への追加編集、復旧候補破棄待機、nativeファイル準備待機、フォント準備中の編集、破損作品のrollback、終了準備中の追加変更について実native応答を遅延させ、旧結果が作品を上書きしない29項目を確認しました。通常の統合28・再起動11・制作191も最終ソースで再実行しています。
