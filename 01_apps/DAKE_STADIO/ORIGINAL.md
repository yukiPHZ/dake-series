## 目的と到達点

日常の写真・画像編集と、文字・図形・ベクターパス制作を一つの作品内で進め、編集状態を保存して後日続きを作り、用途に合う形式へ書き出せる Windows 日本語制作アプリにする。対象はサムネイル、告知画像、バナー、図解、印刷前のラフ、簡単なロゴ・イラストなどの制作である。

## 技術選定と責務

| 項目 | 選定 | 理由・負担 |
| --- | --- | --- |
| Windows シェル | Electron 44.4.5 | 日本語入力、OS フォント、Canvas、ローカルファイルダイアログを一つの実行環境で扱える。Chromium 同梱による配布容量を受け入れる |
| シーンと操作 | Fabric.js 7.4.0 | 図形・文字・パス・画像・グループの選択と変形を共通化し、SVG/JSON の入出力基盤を使う |
| 画素編集 | Canvas の画像バッファ | ブラシと消しゴムは画像の実画素を変更する。単に上へ線を置いて画像編集と呼ばない |
| 文書形式 | バージョン付き `.dake` JSON | シーン、画面寸法、レイヤー属性、埋め込み画像を保持する。画像のリンク切れを避ける |
| 構築 | esbuild 0.25.12 | ローカル依存から renderer を束ねる。実行時 CDN と開発サーバー依存を除く |
| 配布 | Electron runtime とアプリの一フォルダ | Node.js やブラウザーの追加導入を利用者へ要求しない。exe だけの単独コピーは不可 |

Fabric の成熟した選択・変形・SVG 基盤を利用する一方、作品の保存、履歴、画像画素処理、日本語 UI、異常時の保護は STADIO が責任を持つ。Web サイトのラッパーではなく、インストール後の制作をローカルで完結するデスクトップアプリにする。

renderer は表示・編集状態を担い、main process はファイルダイアログ、許可したファイル操作、復旧ファイル、終了時保護を担う。preload に狭い API 境界を置く。renderer へ任意の Node.js 実行や任意パス書込みを公開しない。外部ページへの遷移・新規ウインドウ・不要な権限要求を許可しない設計とする。

UI 文言は単一ファイル `src/ui-text.json` の UI_TEXT を正本として一元管理する。ネイティブメニュー・ファイルダイアログ文言は同ファイルの `desktop` 配下に置く。アプリ名、ウインドウ名、著作権、ボタン、ラベル、状態、エラー、ヘルプをここから使う。共通フッターは編集領域を圧迫しない位置・情報量にする。

## 統合作品モデルと 0.1.0 の実装

以下は実装済みの機能である。全組合せを検証済みという意味ではない。実操作、自動検証、未確認の境界は TEST_REPORT.md で区別する。

| --- | --- |
| 作品 | サイズ指定、新規、画像とベクターの混在、背景、ズーム・画面に合わせる、作品範囲の切り抜き |
| 画像 | 画像読込み、ピクセルブラシ、消しゴム、編集可能な明るさ・コントラスト・彩度・白黒調整とリセット、移動・変形 |
| ベクター | 四角形・楕円・三角形・直線、編集可能な文字、三次ベジェパス、ノード・ハンドル編集、塗り・線・2色グラデーション |
| 構成 | 前後順、表示・非表示、ロック、複製、削除、グループ・解除、整列・反転、移動・拡大縮小・回転、画像レイヤーへ変換 |
| 履歴 | 画像画素の変更も含む取り消し・やり直し。新しい操作でやり直し分岐を破棄 |
| 保存 | 編集可能な `.dake`、画像埋め込み、保存・別名保存、終了後の再読込み |
| 書き出し | PNG / JPEG / WebP / SVG。作品保存と成果画像の書き出しを明確に分ける |
| 保護 | 原画像を変更しない、保存の一時ファイル置換、前回保存バックアップ、復旧データ、未保存終了保護 |

キャンバス中央、左に作成ツール、右に選択物の設定とレイヤー、上に作品の保存・読込み・書き出しを置く。操作対象を切り替えても同じ作品が残り、画像用とベクター用に作品を移送しない。通常ホイールで表示移動、Ctrl＋ホイールでズームする。表示移動は作品を未保存状態にしない。未実装ボタンを押せる状態で並べない。

作品の上限は各辺 8192 px・面積 32,000,000 画素、文書読込みは最大 2000 オブジェクト。画像書き出しは各辺 16384 px・64,000,000 画素以内。ファイル読込み・作品保存データは 128 MiB 以内。これらは入力制限であり、上限まで快適に編集できるという性能保証ではない。

履歴は最大 50 状態で、概算 96 MiB の予算に応じて古い状態を減らす。最低1回の取り消しを残すため、96 MiB は厳密なメモリ上限ではない。埋込み画像の共有で重複保持を抑えるが、大画像の画素変更には負荷が残る。1回の筆操作は1履歴。作品を開き直すと編集可能な状態は戻るが、前セッションの取り消し履歴は継続しない。

## 入出力・保存・データ保護

`.dake` は最終画像ではなく再編集用の作品ファイルである。ラスターは埋め込み画像、ベクターと文字は編集情報を保持する。元の画像ファイルは読取り素材として扱い、画素編集は作品内のコピーへ行う。

保存は同じディレクトリの一時ファイルへ書き、書込みが完了してから対象を置換する。既存作品を上書きする時は前回保存を `<作品名>.dake.bak` に一世代残す。保存失敗を成功表示にしない。失敗時に未保存状態を消さない。

復旧用データの保存先は `%APPDATA%\DAKE STADIO\recovery.json` とその `.bak`。編集停止後に通常保存と独立した復旧候補を保存し、次回起動時はユーザーが復旧を選べる。最新候補が破損していれば有効な前世代へ戻る。通常保存が成功し、その保存以降の変更がない場合は古い復旧候補を消す。正常終了でも保存または明示的な未保存破棄を確認して復旧候補を消す。自動保存へ届く前の直近操作までは復旧できない場合がある。QA では `STADIO_USER_DATA` 環境変数で専用領域を指定し、本番利用者の復旧データを触らない。

破損した JSON、未知の形式バージョン、外部リソースを参照する素材、不正な寸法・過大な入力は妥当性検査を行う。画像を事前にデコードし、現在の作品を置き換える前に検証する。読込みに失敗しても現在の作品を壊さない。書き出し先が配置済み元画像やそのハードリンクの場合も上書きを拒否する。確認済みの異常ケースは検証報告へ記録する。

PNG / JPEG / WebP は合成した画像として出力する。SVG は対応する図形・パス・文字をベクターとして、画像を埋め込みラスターとして保持する。SVG への出力が作品履歴や全編集属性の保存を保証するわけではないため、続きの制作には `.dake` を使う。文字の見え方は受け取り先のフォント環境に依存し、フォントファイルは同梱・埋込みしない。

## 応答性と検証方針

通常操作には即時に選択・カーソル・状態の反応を返す。保存中、書き出し中、完了、失敗を混同しない。不要な画像再読込みやシーン再生成を減らす。非同期処理は古い結果が新しい作品へ混ざらないようにし、保存要求を描画用の「最新だけ処理」で捨てない。

実測対象は起動、通常制作、複数レイヤー、画像読込み・画素編集、連続取り消し、保存・再読込み、書き出し、作品切替・終了、破損入力、保存失敗、復旧である。通常作品と負荷作品のサイズ・オブジェクト数・測定方法を明記する。自動テストに加え、実アプリの UI を操作して実ファイルを作る。

目標は DAKE 操作品質基準に沿う即応性であるが、試験前に「高速」「停止しない」と断定しない。画素サイズ、履歴によるメモリ使用、renderer での同期描画は測定し、未達・未検証は制約として開示する。

## 0.1.0 の境界と段階的な発展

現時点で専門印刷用 CMYK / ICC カラーマネジメント、PSD / AI / PDF の編集読込み、Adobe 独自効果との完全互換、大規模出版・DTP、RAW 現像、全プロ用途の代替を約束しない。選択範囲・レイヤーマスク・パスの集合演算、筆圧、縦書き、複数ページは未実装。巨大画像・大量レイヤー・長時間の履歴保持・多様な GPU と DPI の網羅検証も残る。

段階は統合基盤を弱めるためでなく、実制作を着実に代替する順序として置く。

1. **現在の評価版**: 同じ作品上の画像画素編集とベクター制作、選択・構成・履歴、保存と再編集、一般形式への書き出しを最後まで通す。保存保護と操作品質を先に検証する。
2. **日常制作の深化**: 実評価をもとに選択範囲・マスク、より高度な色調整、整列・ガイド・スナップ、ベクターの結合・型抜き、文字組みを優先する。保存形式の互換性と回帰テストを同時に育てる。
3. **大きな作品と互換性**: タイル化・差分履歴・バックグラウンド処理、複数アートボード、色管理、交換形式を検討し、各領域の正確さを実ファイルで確認してから対応表へ加える。

未完了機能は UI の仮処理で代用しない。このロードマップは全項目を 0.1.0 に実装済みとするものでも、次の開発を自動公開する指示でもない。

サンプル画像はコードで生成した抽象図形・グラデーションで、ユーザーの写真・秘密情報・他製品画像は使わない。配布は未署名。SmartScreen の表示、署名付きインストーラー、別 PC への移設は未検証。

### 検証からの改善判断

- 表示ズーム・画面移動を編集の変更判定から外し、表示操作だけでは未保存にしない。
- Fabric 7 の中央原点に対しサンプル文字・パスの左上原点を明示して配置を修正。
- 壊れた画像を黙って飛ばす挙動を、事前デコード・置換前検証・現在作品保持へ変更。
- ブラシ時のヒットテストで選択画像が失われる問題を修正。ネイティブマウスで画素描画・消去を検証。
- 閉じたパス先頭ノードの移動で他のアンカーがずれる問題を修正し、回帰試験を追加。
- 通常保存後に古い復旧候補が残る問題を修正。保存世代を照合し、保存以後の新しい編集は消さない。
