# DAKE STADIO 0.4.0-eval.1

画像編集とベクター制作を行き来するWindows向けの統合制作アプリです。今回の評価版はフォントの再検証、作品タブ、編集可能なDAKE部品、非破壊補正・マスク、出力確認を結合しています。仕様正本は [ORIGINAL.md](ORIGINAL.md)、開発・検証記録は [TECHNICAL_RECOVERY.md](TECHNICAL_RECOVERY.md) です。

## 起動

ZIPを新しいフォルダへすべて展開し、DAKE_STADIO.exeを起動してください。resources、locales等は同じフォルダに置きます。Node.jsの導入は不要。旧0.3.0フォルダを上書きする必要はありません。

旧版が起動中の場合は、旧版で作品を保存して終了してから、新版のDAKE_STADIO.exeを起動してください。同じ利用設定で同時に起動すると、起動要求が旧プロセスへ転送され、新版を開けない場合があります。設定フォルダを削除する必要はありません。旧作品を比較しながら試す場合は、新版では別名保存してください。

## 短い試用手順

1. ロゴを新規作成し、「文字」→「フォントを探す」でWindowsまたはGoogleを選択。Googleは「取得して見本を見る」後に「使う」。見本は編集中の文字に変更できます。保存して logo.dake を作ります。
2. Ctrl+Nで名刺を別タブに作成。「DAKE部品を配置」からlogo.dakeを埋込みます。部品をダブルクリックして子タブを開き、文字や色を変更。配置先の小窓で確認し「配置先へ反映」。親側のUndo1回で戻せます。
3. 写真を追加し「加工」→「写真を補正」。補正は後から変更/解除できます。「透明度マスク」を選び、黒で隠す／白で戻す。画像・マスク・補正範囲の編集対象を確認してください。
4. .dakeとして保存し、終了・再起動・再読込み。部品とマスクを再編集します。
5. 「書き出す」で形式、寸法、品質、透過、プレビューと実測容量を確認して保存します。

塗り／線の色は色面・カラーセット・履歴・登録色から選択でき、作品上のクリックまたはボタンで確定、Escで取消。作品全体の寸法は何も選択していない状態の「配置・ガイド」から変更します。配置画像のトリミングと出力寸法は別操作です。

## 制限と互換性

- 評価版です。大規模な多重部品や巨大写真の長時間性能は引き続き検証が必要です。
- Windows書体は作品へバイトを埋め込みません。同じPCでは再利用できますが、別PCには同じ書体が必要です。Googleの取得済み書体は作品にも保存します。収録されていない文字は代替表示の警告が出ます。
- v1/v2を読み込めます。保存はv3になり旧アプリでは開けません。元ファイルの前世代は.bakに残ります。Undo履歴は再起動では保持しません。
- 外部リンクは自動更新しません。再起動後の更新は元ファイルを選び直します。子編集で元ファイルを上書きしません。
- マスクは画像対象・矩形選択対応。自由形選択、自動被写体抽出、色別RGB曲線はありません。
- PDFはRGBラスター1ページ。文字/ベクターの保持、CMYK/ICC、PDF/X、TrimBox/BleedBox、トンボは未対応です。

## 開発

Electron / Fabric / Paper.js / opentype.js / ローカルworker。新規依存の追加なし。Node 22.12以降で npm ci、npm run build、npm start。評価ビルドは npm run package:evaluation。公開・pushは行っていません。
