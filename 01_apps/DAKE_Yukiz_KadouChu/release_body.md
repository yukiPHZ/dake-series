# Dakeユキズ稼働中 v0.1.0

動画素材を取り込み、補助脳で投稿準備を整える制作コンソールです。

## できること

- 動画ファイルの取り込み
- FFmpeg / yt-dlp / Ollama / GitHub CLI / Wrangler の環境チェック
- NVENC利用可否の確認
- ffprobeによる動画情報取得
- faster-whisper利用時の文字起こし
- Shorts候補JSONの作成
- プレビュークリップ作成
- タイトル案・説明欄雛形の出力
- 処理ログ保存
- 出力フォルダを開く

## まだやらないこと

- YouTubeへの自動投稿
- 自動公開
- 完全自動編集
- PSD編集
- BGM自動ミックス
- 縦動画の高度な自動クロップ
