# Dake昨日タスクメモ

昨日のメモを、今日のタスクに変える実務メモです。
前営業日のメモを左に表示し、右側で今日のメモと今日やることを整理します。

## アプリ概要

`Dake昨日タスクメモ` は、前営業日のメモを読み返しながら、今日の作業に変えるためのDAKEシリーズ用 Windows デスクトップアプリです。

思い出す手間だけ消します。判断は自分でするための、小さなメモです。

## できること

- 前営業日のメモを左側に編集不可で表示する
- 今日のメモを右側で編集する
- 入力内容を日付ごとのJSONに自動保存する
- アプリ終了時にも今日のメモを保存する
- 月曜起動時は金曜メモを前営業日として表示する
- 前営業日のメモがない場合も静かに起動する
- 今日のメモを確認付きでクリアする

## できないこと

- 複数メモ管理
- タグ、検索、カレンダーUI
- 通知、タスク完了チェック
- クラウド同期、AI連携
- Markdownプレビュー
- PDF出力、印刷
- 祝日判定
- ログイン、外部API通信

## 使い方

1. 起動すると、左に前営業日のメモが表示されます。
2. 右の `今日のメモ` に、今日やることや気になることを書きます。
3. 入力内容は自動保存されます。
4. 念のため保存したい場合は `今日のメモを保存` を押します。
5. 今日のメモを空にする場合は `今日のメモをクリア` を押し、確認後にクリアします。

## 保存仕様

メモはアプリフォルダ配下の `data/memos/` に日付別JSONで保存します。

```text
data/
  memos/
    YYYY-MM-DD.json
```

JSONの内容は以下の形式です。

```json
{
  "date": "2026-05-13",
  "memo": "...",
  "updated_at": "2026-05-13T18:20:00+09:00"
}
```

前営業日は土日だけをスキップして判定します。祝日は考慮しません。

## ビルド方法

アプリフォルダで以下を実行します。

```bat
build.bat
```

ビルドに成功すると、`dist/DakeYesterday_Task_Memo.exe` が作成されます。
