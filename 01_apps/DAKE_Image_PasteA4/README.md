# Dake貼る

見えているウインドウを貼って、A4画像として資料化するDAKEシリーズの単機能アプリです。

初期版は、起動中ウインドウ一覧から対象を選んで「貼る」方式です。ドラッグ＆ドロップで即貼り付ける操作は、Windows環境での安定性確認を優先し、MVPでは入れていません。

## アプリ概要

「今見ているもの」を、そのままA4のPNG画像にします。

スクショ編集、PDF編集、注釈作成は行いません。貼る、並べる、出すだけに絞っています。

## できること

- 起動中の表示ウインドウ一覧を更新
- 一覧から選んだウインドウをA4キャンバスへ貼り付け
- 貼った画像をマウスドラッグで移動
- 選択画像を「小さく」「大きく」で縦横比固定のまま拡大縮小
- 選択画像の削除
- すべてクリア
- A4縦 / A4横の切り替え
- A4比率のPNG画像として保存
- 保存後に保存フォルダを開く

## できないこと

- テキスト入力
- 矢印、線、図形、注釈の追加
- 画像加工、フィルタ、透明度変更
- 回転、自由変形
- PDF編集、PDF出力
- PowerPoint出力
- 複数ページ
- テンプレート保存
- プロジェクト保存
- 初期版でのウインドウドラッグ＆ドロップ貼り付け

## 使い方

1. 「更新」で起動中ウインドウ一覧を更新します。
2. 貼りたいウインドウを一覧から選びます。
3. 「貼る」を押します。
4. A4キャンバス上で画像をドラッグして配置します。
5. 必要に応じて「小さく」「大きく」「削除」「クリア」を使います。
6. A4縦 / A4横を選びます。
7. 「画像出力」でPNG画像を保存します。

## 注意事項

- Windows専用です。
- 取得対象は見えているウインドウです。ウインドウが他の画面に隠れている場合、期待どおりに取得できないことがあります。
- 最小化されたウインドウ、タイトルのないウインドウ、自分自身のウインドウは一覧から除外します。
- 一部のアプリや管理者権限の違うウインドウは、OS側の制限で取得できない場合があります。
- 初期版は安定性優先のため、ウインドウ一覧から貼る方式です。

## ビルド

```powershell
build.bat
```

`dist/DakeImage_PasteA4.exe` を生成します。exeはGit管理しません。
