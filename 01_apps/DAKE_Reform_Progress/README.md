# Dakeリフォーム進捗管理

## アプリ概要

リフォーム工事の進捗に合わせて工程日程を直し、A4縦1枚のカレンダー風PDFとして出力するDAKEシリーズのWindows向けアプリです。

工程管理システムではなく、現場・自社・業者確認用の最新版PDFをすぐ作るための単機能ツールです。案件管理、履歴管理、通知、メール送信、Excel出力には対応しません。

## v1.1更新内容

- exeと同じフォルダに `reform_progress_project.json` を保存し、起動時に自動復元します。
- PDF上で2日以上の工程を薄い帯で固まり表示します。
- カレンダープレビューの左端、中央、右端ドラッグで開始日変更、工程移動、終了日変更を使い分けできます。
- 開始日を1日目とした45日目の参考日を表示します。終了日は自動入力しません。
- 終了日は開始日から56日以内に制限します。46日表示は引き続き使用できます。
- DAKE共通アイコンをウインドウとexeに反映します。

## 使い方

1. `main.py` を起動します。
2. 現場名、支店名、担当者名、電話番号、開始日、終了日、保存先を入力します。
3. 必要な工程だけチェックし、工程名、開始日、終了日、状態を調整します。
4. 進捗に合わせて工程をドラッグ、または日付を直接入力します。
5. 大きく組み直す場合は「日程再配置」を押します。
6. 続きから編集したい場合は「状態保存」を押します。
7. 「PDF作成」を押すと、保存先にA4縦カレンダーPDFが作成されます。

開始日、終了日は `2026/05/29`、`2026-05-29`、`2026.05.29`、`20260529` の形式で入力できます。
開始日の横に表示される「45日目」は参考表示です。終了日は自動入力されません。
終了日は開始日から56日以内にしてください。

## 進捗更新の考え方

- 標準工程は18件を初期表示します。
- 自由工程は3件あり、チェック、工程名、開始日、終了日がそろったものだけPDFに出力します。
- 状態は「未着手」「作業中」「完了」「延期」「保留」から選べます。
- 「日程再配置」はチェックあり工程を上から順に並べ直します。
- 「完了」の工程は再配置しても開始日・終了日を動かしません。
- 土日は工事日に含めず、工程表示も原則出しません。
- 「状態保存」で `reform_progress_project.json` に現場情報、日付、保存先、工程一覧を保存します。
- 物件フォルダにexeを置いて使うと、そのフォルダ内の保存データを次回起動時に自動読込します。

## ドラッグ操作

- 工程リスト上で工程行を上下にドラッグして並び替えできます。
- 工程リストには上下ボタンもあり、ドラッグが使いにくい場合でも順番を変更できます。
- カレンダープレビュー上の工程ブロック左端をつかむと、開始日を変更できます。
- カレンダープレビュー上の工程ブロック中央をつかむと、工程全体を移動できます。
- カレンダープレビュー上の工程ブロック右端をつかむと、終了日を延長または短縮できます。
- 土日に移動した場合は、直近の平日に補正し、ステータスに表示します。
- 日付の直接入力と「日程再配置」も残しているため、ドラッグだけに依存しません。

## PDF出力仕様

- PDFタイトル：リフォーム進捗カレンダー
- 用紙：A4縦
- ページ数：1ページ固定
- 表示形式：日曜始まり、横7列のカレンダー風
- 表示範囲：指定期間のみ
- 前月・翌月の補完日は空欄
- 必要週数からセル高さを自動計算
- 終了日のセルに「完工」を表示
- 2日以上の工程は平日セルだけに薄い帯で表示
- 週をまたぐ工程は週ごとに帯を分割
- 土日は淡い背景、土日の曜日文字は淡い赤
- 土日に工程名は原則表示しません
- 状態記号：完了「✓」、作業中「●」、延期「△」、保留「…」、未着手は記号なし
- DAKE共通フッターは現場共有用として控えめに表示します

## ビルド方法

同じフォルダ内で以下を実行します。

```bat
build.bat
```

`dist` フォルダに `DakeReform_Progress.exe` が作成されます。
