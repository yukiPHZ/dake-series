# Dakeマジでメモ

保存ボタンを押さずに、今の考えをそのまま置いておける実務用メモアプリです。
閉じても前回の続きが自動で戻るため、机の上に置きっぱなしのメモとして使えます。

## アプリ概要

`Dakeマジでメモ` は、作業中の思考、計算、確認事項を一時的に置くためのDAKEシリーズ用 Windows デスクトップアプリです。
メモ管理ではなく、今の作業台を軽く保つことを目的にしています。

## できること

- 左に補助メモ、右にメインメモを置いて入力する
- 右側のメインメモを少し広く使う
- 入力内容を自動で内部保存する
- 次回起動時に前回の内容を自動復元する
- メインメモと補助メモを個別にリフレッシュする
- 閉じる時に保存確認を出さず、そのまま終了する

## やらないこと

- 保存ボタン、名前を付けて保存、ファイル選択
- 複数ノート管理、タブ、フォルダ管理
- Markdownプレビュー、リッチテキスト、チェックリスト
- メモの検索、分類、同期
- 多機能メモアプリ化

## 使い方

1. 起動したら、そのままメモを入力します。
2. 左の `補助` に参照や一時置き、右の `メイン` に主思考を書きます。
3. 終わったらそのまま閉じます。保存確認は出ません。
4. 空に戻したい欄だけ `補助をリフレッシュ` または `メインをリフレッシュ` を押します。

## 保存について

入力内容は `DAKE_Maji_Memo_config.json` に自動保存されます。
このファイルはユーザー環境依存のためGit管理しません。

## ビルド方法

アプリフォルダで以下を実行します。

```bat
build.bat
```

`dist/DakeMaji_Memo.exe` が作成されます。
