# 補助脳BRAINZ v0.1

ローカルの会話・仕様・メモを忘れず探すための記憶検索アプリです。

## できること

- ローカルフォルダのtxt / md / json取り込み
- SQLiteによる記憶DB作成
- 全文検索
- うろ覚え検索
- Ollama / CUDA / GPU状態チェック
- ChatGPT用まとめ生成
- Codex用素材生成
- 検索ログ保存

## まだやらないこと

- OpenAI API接続
- 自動投稿
- ChatGPT / Codexへの自動送信
- Claude / Gemini自動連携
- PDF OCR
- 音声文字起こし
- クラウド同期
