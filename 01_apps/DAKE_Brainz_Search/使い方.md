# 補助脳BRAINZ 使い方

## これは何？

補助脳BRAINZ は、
ChatGPTやCodexの会話、
仕様メモ、
実装結果を、
ローカルで忘れず探すための記憶検索アプリです。

AIそのものではありません。

記憶して、
探して、
繋ぎ直すための補助脳です。

---

## 最初にやること

### 1. BRAINZを起動する

`DakeBrainz_Search.exe`

を起動します。

左下で、

- CUDA
- OLLAMA
- SQLITE

などの状態を確認できます。

OLLAMAがなくても動きます。

---

### 2. 記憶フォルダを選ぶ

まず、自分の記録を置くフォルダを決めます。

例：

```text
brainz_memory/
├ chatgpt/
├ codex/
├ ideas/
├ thoughts/
└ README/
```

txt / md / json を入れておけば、
BRAINZがindex化します。

---

### 3. ChatGPT export を取り込む

ChatGPTから export zip をダウンロードします。

BRAINZの：

`ChatGPT exportを取り込む`

ボタンから読み込みます。

会話タイトル、
本文、
role、
conversation が検索対象になります。

---

### 4. Codex結果を取り込む

Codexの完了報告を、
貼り付けるか、
.txt / .md で保存して取り込みます。

commit hash や、
修正ファイル、
build結果も記憶できます。

---

## 検索する

うろ覚えで大丈夫です。

例：

- 補助脳
- quiet
- Cloudflare
- 青
- 稼働中
- DAKE
- Codex

など。

Semantic Search がONなら、
意味的に近い記録も探します。

---

## Related Memory

検索結果を選ぶと、
関連する記録が表示されます。

- 関連会話
- 関連実装
- 関連README
- 関連アイデア

などを辿れます。

---

## Memory Flow

Memory Flow は、
「思考の流れ」
を見るための機能です。

単語を探すだけではなく、

「どう繋がって進化したか」

を辿れます。

---

## Remote Queue の使い方

Remote Queue は、
スマホや別端末からBRAINZへ小さな指示を渡すための命令箱です。

BRAINZが起動していて、
Remote Queue が ON の場合、
指定フォルダに置かれた `.md` / `.txt` / `.json` を検出します。

外部へ送信はしません。

処理済みのファイルは `processed/` へ、
失敗したファイルは `failed/` へ移動します。

---

### 最初に設定すること

BRAINZで Remote Queue Folder を選びます。

そのあと、
Enable Remote Queue を ON にします。

スマホや別端末から使う場合は、
OneDrive、
Dropbox、
Google Drive、
Syncthing、
LAN共有などの同期フォルダを指定すると便利です。

BRAINZは同期サービスとは直接通信しません。

---

### search の例

検索したい内容を置きます。

```md
# BRAINZ TASK

type: search
query: quiet workflow
note: ChatGPTに戻すため、関連する記憶を探したい
```

BRAINZは query を検索欄へ入れます。

勝手にChatGPTへ送信はしません。

---

### note の例

その場で思いついたメモを置きます。

```txt
type: note
note: スマホから置いた補助脳メモ

次にBRAINZで探したいこと。
quiet workflow と Remote Queue の運用をつなげる。
```

note は記憶として取り込まれます。

あとから通常検索や Semantic Search で探せます。

---

### handoff_chatgpt の例

ChatGPTへ渡す前の候補を作りたい時に使います。

```md
# BRAINZ TASK

type: handoff_chatgpt
query: 補助脳 Remote Queue
note: 過去の流れをまとめてChatGPTへ戻したい
```

BRAINZは候補として受け取ります。

自動送信はしません。

---

### handoff_codex の例

Codexへ渡す前の材料を探したい時に使います。

```json
{
  "type": "handoff_codex",
  "query": "Remote Queue processed failed",
  "note": "次の修正用に関連実装履歴を探す"
}
```

Codex用の素材候補として扱います。

自動でCodexを操作しません。

---

### import の例

別のローカルファイルを取り込みたい時に使います。

```json
{
  "type": "import",
  "path": "C:\\Users\\yukiz\\Documents\\brainz_memory\\ideas\\quiet_workflow.md"
}
```

存在するローカルファイルだけを取り込みます。

URLから勝手にダウンロードはしません。

---

### 運用のコツ

スマホでは、
短い `.txt` を置くだけでも十分です。

例：

```txt
search: DAKE Git rules
```

家PCのBRAINZが気づいて、
命令箱として受け取ります。

置く。
気づく。
記憶につながる。

---

## handoffを作る

検索結果から：

- ChatGPTまとめ
- Codex素材

を生成できます。

これをChatGPTやCodexへ貼ることで、
過去の流れを引き継げます。

---

## BRAINZの役割

ChatGPTが考える。

Codexが実装する。

BRAINZが覚えて、
探して、
繋ぎ直す。

---

## 補助脳の考え方

補助脳が提案し続ける。

菊田が選び続け、
決め続ける。

補助脳が決定を反映し続ける。

---

## まだやらないこと

現在のBRAINZは：

- 自動投稿
- 自動commit
- 自動ChatGPT操作
- 自動Codex操作

は行いません。

まずは、
「忘れない」
「戻れる」
「繋げられる」

ことを優先しています。
