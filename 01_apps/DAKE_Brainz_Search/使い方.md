# 補助脳BRAINZ 使い方

## これは何？

補助脳BRAINZ は、
ChatGPTやCodexの会話、
仕様メモ、
実装結果を、
ローカルで忘れず探すための記憶検索アプリです。

AIそのものではありません。

記憶して、
探して、
繋ぎ直すための補助脳です。

---

## 最初にやること

### 1. BRAINZを起動する

`DakeBrainz_Search.exe`

を起動します。

左下で、

- CUDA
- OLLAMA
- SQLITE

などの状態を確認できます。

OLLAMAがなくても動きます。

---

### 2. 記憶フォルダを選ぶ

まず、自分の記録を置くフォルダを決めます。

例：

```text
brainz_memory/
├ chatgpt/
├ codex/
├ ideas/
├ thoughts/
└ README/
```

txt / md / json を入れておけば、
BRAINZがindex化します。

---

### 3. ChatGPT export を取り込む

ChatGPTから export zip をダウンロードします。

BRAINZの：

`ChatGPT exportを取り込む`

ボタンから読み込みます。

会話タイトル、
本文、
role、
conversation が検索対象になります。

---

### 4. Codex結果を取り込む

Codexの完了報告を、
貼り付けるか、
.txt / .md で保存して取り込みます。

commit hash や、
修正ファイル、
build結果も記憶できます。

---

## 検索する

うろ覚えで大丈夫です。

例：

- 補助脳
- quiet
- Cloudflare
- 青
- 稼働中
- DAKE
- Codex

など。

Semantic Search がONなら、
意味的に近い記録も探します。

---

## Related Memory

検索結果を選ぶと、
関連する記録が表示されます。

- 関連会話
- 関連実装
- 関連README
- 関連アイデア

などを辿れます。

---

## Memory Flow

Memory Flow は、
「思考の流れ」
を見るための機能です。

単語を探すだけではなく、

「どう繋がって進化したか」

を辿れます。

---

## handoffを作る

検索結果から：

- ChatGPTまとめ
- Codex素材

を生成できます。

これをChatGPTやCodexへ貼ることで、
過去の流れを引き継げます。

---

## BRAINZの役割

ChatGPTが考える。

Codexが実装する。

BRAINZが覚えて、
探して、
繋ぎ直す。

---

## 補助脳の考え方

補助脳が提案し続ける。

菊田が選び続け、
決め続ける。

補助脳が決定を反映し続ける。

---

## まだやらないこと

現在のBRAINZは：

- 自動投稿
- 自動commit
- 自動ChatGPT操作
- 自動Codex操作

は行いません。

まずは、
「忘れない」
「戻れる」
「繋げられる」

ことを優先しています。

---

## 現在の段階

現在のBRAINZは：

- txt / md / json
- ChatGPT export
- Codex結果
- Semantic Search
- Related Memory
- Memory Flow

まで対応しています。

今後：

- Whisper
- OCR
- PDF
- Claude/Gemini
- スクショ
- 音声メモ

などへ拡張予定です。

---

## 最後に

BRAINZは、
AIの代わりではありません。

思考を、
止めずに、
続けるための記憶層です。
