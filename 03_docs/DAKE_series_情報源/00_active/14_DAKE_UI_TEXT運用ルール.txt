# encoding: utf-8

【絶対ルール】
すべてのファイルはUTF-8で扱うこと。
文字コードを確認する質問は禁止。

【DAKEシリーズ｜UI_TEXT運用ルール】

■ 目的
・DAKEシリーズの日本語UI文言を安定して管理する
・文字化けを防ぐ
・ChatGPT / Codex 実装時のブレを減らす
・文言差し替えを容易にする

■ 基本ルール
・UI文言はすべて変数化する
・原則として text="" に日本語を直接書かない
・UI文言はファイル上部にまとめる
・文言変更は表示コードではなく、文言定義側で行う

■ 推奨構成
・APP_NAME
・WINDOW_TITLE
・COPYRIGHT
・UI_TEXT = { ... }

■ UI_TEXTに入れる対象
・見出し
・説明文
・ボタン文言
・空状態文言
・ドラッグ中文言
・処理中文言
・完了文言
・エラー文言
・フッター文言
・メッセージボックス文言

■ 命名ルール
・英数字とアンダースコアで統一する
・意味が一目で分かる名前にする
・アプリ共通文言は共通キー名を優先する
・アプリ固有文言は接頭辞を付けてもよい

■ 禁止事項
・長い日本語を直接ウィジェットに埋め込む
・同じ意味の文言を複数箇所で別記述する
・文字化けした文言をその場だけ直して放置する
・WordやPDFを正本にしない

■ 保存ルール
・情報源テキストは UTF-8 で保存する
・Pythonソースも UTF-8 で保存する
・コピペ後は表示崩れがないか確認する

■ ChatGPT / Codex 指示ルール
・毎回「UI文言はすべて変数化してください」と指示する
・新規文言追加時は UI_TEXT ブロックごと出力させる
・差分修正でも文言が増える場合は UI_TEXT 側の変更を含める

■ 判断基準
・文言が再利用されるか → YESなら変数化
・状態に紐づく文言か → YESなら変数化
・ブランド表記か → YESなら変数化
・一度でも文字化けしたか → YESなら必ず変数化

【共通実装指示】
・UI文言はすべて変数化してください
・日本語文言を text="" に直接書かないでください
・APP_NAME、WINDOW_TITLE、COPYRIGHT、UI_TEXT を上部にまとめてください
・新規文言を追加する場合は UI_TEXT 定義も同時に更新してください
・文字化け対策として Python ファイルは UTF-8 前提で扱ってください

【追記｜フッター文言管理ルール】

■ フッター文言も UI_TEXT に含める
・footer_left
・footer_link_1
・footer_link_2
・footer_copyright

■ フッター用の追加キー
・footer_separator

■ 実装ルール
・フッター文言は text="" に直接書かない
・リンク対象の判定は文言単位で行う
・区切り文字は独立した文言として管理する
・左右ブロックでも文言定義は分散させず UI_TEXT に一元化する

■ DakePDF結合の確定キー
・footer_left = "シンプルそれDAKEシリーズ"
・footer_link_1 = "戸建買取査定"
・footer_link_2 = "Instagram"
・footer_separator = " ｜ "
・footer_copyright = "© 2026 しまりす不動産 — Vibe-Coded by Yukihiko Kikuta"

【追記｜UI_TEXT強制ルール】

■ 強制ルール
・UI_TEXT未使用の日本語が1つでも存在する場合はNGとする

■ 対象
・ボタン文言
・見出し
・説明文
・状態表示
・フッター
・ダイアログ
・例外メッセージ

■ 実装ルール
・text="" に日本語を直接書かない
・必ず UI_TEXT または定数を経由する

■ レビュー基準
・直書き日本語が存在するかを確認する
・1つでもあれば修正対象とする

■ 目的
・文字化け防止
・文言一元管理
・修正コスト削減
・ChatGPT / Codex 安定化

【追記｜UI_TEXTレビュー強制ルール】

■ レビュー工程（必須）
以下を必ず確認する

① text="" に日本語が存在しないか
② UI_TEXTに未定義の文言がないか
③ 同一意味の文言が重複していないか
④ フッター文言がUI_TEXTで管理されているか

■ NG判定
・1つでも直書き日本語があればNG

■ Codex指示テンプレ
必ず以下を含める

「UI文言はすべてUI_TEXTで管理してください。
 text="" に日本語を直接書かないでください。」

■ 理由
・量産時の修正コスト削減
・文字化け防止
・統一UI維持
