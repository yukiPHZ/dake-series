【01_DAKE_実装原則_応答性とUI.txt】

【DAKEシリーズ実装原則】

■ 基本思想
・処理は止まってもいい
・UIは止めるな
・応答なしは敗北

■ 判断基準
・0.5秒以上UIが無反応なら設計見直し
・3秒無反応は危険
・5秒無反応は実質敗北

■ 設計原則
・重い処理をメインスレッドで回さない
・分割処理
・非同期処理
・即時フィードバック
・進捗表示
・遅延読み込み
・見えている範囲だけ描画する

■ UIの意味定義
・見た目
・操作
・反応
・状態表示
・完了通知
・エラー表示

■ 責務分離
・UI層：表示 / 入力受付 / 状態表示
・制御層：入力検証 / 処理指示 / 状態管理
・処理層：PDF操作 / 画像処理などの実処理
・通知層：queue / after などでUI更新

■ フィードバック設計
・0.1〜0.2秒以内に反応を返す
・進捗表示は必須
・必要に応じてフェーズ表示を行う
  例：解析中 → 処理中 → 保存中

■ UI判断ルール
・迷うか？ → NG
・止まるか？ → NG
・一瞬で理解できるか？ → OK

■ 動きの判断
・それは演出か？ → NG
・それは反応か？ → OK

■ 状態設計
・状態が同じならUIも同じ
・状態が違うならUIを明確に分ける
・同じ意味の情報を複数回表示しない

■ 実装時チェックリスト
・UIで重い処理をしていないか
・進捗が見えるか
・キャンセルできるか
・見えている範囲だけ描画しているか
・低スペックPCでも止まらないか


■ 見送り確定事項
・ドラッグマウスオーバー時のUI変化は、現時点では実装しない

■ 見送り理由
・Tkinter + DnD では安定実装コストが高い
・イベント取得やOS差異の影響で沼りやすい
・軽量性 / 安定性 / 応答性に対して優先度が低い
・実装負荷に対してユーザー価値が小さい

■ 採用する代替
・空状態中央ボックスでドラッグ＆ドロップ対応を明示する
・左下ステータスで読み込み中を表現する
・完了表示は知覚完了ベースで切り替える
　＝ 全カードのサムネイル / ファイル名 / ページ数が出そろってから「準備完了」

■ UI判断ルール
・Tkinterで難度が高く、安定性を下げるUI演出は採用しない
・実装難度が高い場合は、先に代替案を検討する
・演出より、状態表示・配置・完了タイミングを優先する

【追記｜UI文言実装原則】

■ 原則
・UI文言は表示要素の一部ではなく、状態設計の一部として扱う
・同じ意味の文言は同じ変数を使う
・状態が違うなら文言も明確に分ける
・空状態、処理中、準備完了、保存中、完了、エラーはそれぞれ専用文言を持つ

■ 文字化け対策
・日本語文言は直接UI部品に埋め込まない
・文言は定数化して1か所管理する
・UI修正時に文言変更がある場合は、表示コードではなく文言定義側を修正する

■ 判断ルール
・一時しのぎの直接書き換えはしない
・繰り返し使う文言は必ず変数化する
・日本語が多い画面ほど先にUI_TEXTを整備する

■ 実装優先
・見た目調整より先に文言の一元化を行う
・文字化け再発防止はUI品質の一部とみなす

【追記｜ステータステキスト拡張仕様】

■ 基本方針
・処理中表示は「状態表示」であり、演出ではない
・UIを止めないことを最優先とする
・ブランド表現は状態表示を邪魔しない範囲でのみ許可する

■ 従来仕様
・処理中.
・処理中..
・処理中...
（ドット進行ループ）

■ 新仕様
・短時間処理では従来のドットループのみ表示する
・一定時間以上の処理時のみブランドフレーズを挿入する

■ 発動条件
・処理開始から約1.5〜2秒経過後

■ 表示内容（英語固定）
Simple
Simple, fast
Simple, fast, for real work.

■ 表示ロジック
・処理中ループ → フレーズ → 処理中ループ → フレーズ（繰り返し）

■ UI制約
・左下固定
・フォント変更なし
・サイズ変更なし
・色は補助文字色
・アニメーション禁止（テキスト切替のみ）

■ 禁止事項
・常時フレーズ表示
・派手な演出
・色変更による強調
・中央表示
・日本語化

■ 判断
・それは演出か？ → NG
・それは状態の延長か？ → OK

【追記｜ステータステキスト境界定義】

■ 定義
・時間条件付きのテキスト切替は「状態表示」とみなす
・視覚変化（色変更・アニメーション・動き）は「演出」とみなす

■ 許可
・一定時間後の文言切替
・ドット進行（処理中. → .. → ...）

■ 禁止
・フェード
・色変化による強調
・拡大縮小
・中央表示
・動きのあるアニメーション

■ 判断ルール
・それは状態か？ → OK
・それは演出か？ → NG
