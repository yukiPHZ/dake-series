【DAKE禁止事項｜2026-06-12 現行】

## 正本・情報管理

- ORIGINAL.md 以外を真の正本として扱わない
- 派生ビューだけを直して終わらせない
- generated JSONを手編集しない
- Store側で商品名、価格、説明文、Stripe Payment Link、BOOTH URLを直接編集しない

## UI / 実装

- 多機能化しすぎない
- UIを重くしない
- 日本語UI文言を text="" に直接書かない
- UI_TEXT管理を外さない
- 送信、公開、決済などの外部操作を無確認で自動化しない

## Git / 生成物

- build/ をGit管理しない
- dist/ をGit管理しない
- *.spec をGit管理しない
- *_config.json をGit管理しない
- __pycache__/ と *.pyc をGit管理しない
- exeを通常commitに含めない

## Store / Stripe

次を公開repo、generated JSON、Store JavaScriptへ入れない。

- Stripe Secret
- APIキー
- Webhook Secret
- 決済内部情報
- 個人情報

Stripe Payment Linkは利用できるが、追加・変更する場合は対象商品の ORIGINAL.md へ戻す。
