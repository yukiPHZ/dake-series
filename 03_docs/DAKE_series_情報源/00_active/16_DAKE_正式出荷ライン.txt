## 基本定義

DAKEシリーズでは、GitHub Release公開だけでは正式出荷完了としない。

正式出荷とは、正本から派生ビューが生成または整合され、必要な出荷先へ届いている状態である。

## 正式出荷ライン

```text
ORIGINAL.md
↓
README.md
↓
DAKE_META
↓
release_body.md
↓
assets/screenshot.webp
↓
assets/booth_thumbnail.jpg
↓
booth_product.txt / booth_ready
↓
build
↓
dist/*.exe
↓
GitHub Release
↓
BOOTH
↓
dakeapp.com
↓
store_products.generated.json
↓
dake-store-site同期
↓
store.dakeapp.com商品詳細確認
↓
payment_status確認
↓
Cloudflare反映確認
↓
正式出荷完了
```

## Storeの扱い

store.dakeapp.com は正本ではない。

販売ビューである。

ただし、正式出荷先に含める。

Store表示は ORIGINAL.md 由来の generated JSON から作る。

## CLOSED条件

次が揃うまで正式出荷完了として扱わない。

- ORIGINAL.md 確認
- README / DAKE_META / release_body / booth_product 整合確認
- screenshot.webp
- booth_thumbnail.jpg
- booth_ready
- dist/*.exe
- GitHub Release
- BOOTH導線
- dakeapp.com掲載
- store_products.generated.json再生成
- dake-store-site同期
- store.dakeapp.com商品詳細確認
- payment_status確認
- Cloudflare反映確認

## Store同期

正式出荷時は次を実行する。

```powershell
python tools\store\sync_store_to_site.py
```

同期後に確認する。

- items件数
- payment_status件数
- stripe_ready
- booth_only
- preparing
- not_for_sale
- source_policy
- do_not_edit: true
- shimarisu_pack

## 禁止

- GitHub Releaseだけで完了扱いする
- BOOTHだけで完了扱いする
- Storeだけで完了扱いする
- generated JSONを手編集する
- Store側で商品情報を直接編集する
- Stripe Secret / APIキー / Webhook Secretを公開repoへ入れる
