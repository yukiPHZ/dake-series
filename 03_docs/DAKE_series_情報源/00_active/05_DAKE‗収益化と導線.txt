【DAKE収益化と導線｜2026-06-12 現行】

## 基本思想

DAKEの収益化は、単純な売り場ではなく、DAKEエコシステム内の導線として扱う。

販売導線は重要だが、商品情報の中心ではない。

商品情報の中心は ORIGINAL.md に置く。

## 主要導線

DAKEで扱う導線：

- GitHub Release
- BOOTH
- dakeapp.com
- store.dakeapp.com
- Stripe Payment Link

## Store

store.dakeapp.com は販売ビューである。

正本ではない。

ただし、正式出荷先の一つである。

Store表示は ORIGINAL.md 由来の store_products.generated.json を読む。

## BOOTH

BOOTHは外部販売・配布導線として扱う。

booth_product.txt と booth_ready はBOOTH登録用ビューであり、正本ではない。

BOOTH URLは、公開後に必要な派生ビューへ戻す。

## Stripe Payment Link

Stripe Payment Linkは、自社Storeの購入導線として利用できる。

ただし、Stripeは正本ではない。

次の情報は公開repo、generated JSON、Store JSへ保存しない。

- Stripe Secret
- APIキー
- Webhook Secret

## payment_status

Storeの購入導線は payment_status で扱う。

```text
stripe_ready  = Stripe Payment Linkあり
booth_only    = BOOTH導線のみ
preparing     = 準備中
not_for_sale  = 販売対象外
```
